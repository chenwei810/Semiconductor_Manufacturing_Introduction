# 第 2 部　製程模組

晶圓廠裡的步驟多達數百到上千個，但大部分都是由幾種基本的「製程模組」反覆組合而成。這一部先用一章介紹工廠裡負責各段製程的七個 Module，再逐一介紹每個模組：它在做什麼、用什麼機台、要看哪些指標、常出什麼問題。

實際生產時，晶圓會在這些模組之間反覆循環：鋪上薄膜、微影、蝕刻或佈植、清洗、量測，然後再往上做下一層。介紹完 Module 的分工之後，本書從微影開始，因為它是整個循環的核心。
