# 第 2 部　プロセスモジュール

ファブには数百から千を超える工程がありますが、その大部分はいくつかの基本的な「プロセスモジュール」の組み合わせです。この部では、まずファブで工程を分担する 7 つのモジュールを 1 章で紹介し、そのあと各モジュールを順に取り上げ、何をするのか、どんな装置を使うのか、どの数値が重要か、どんな問題が起きやすいかを説明します。

実際の生産では、ウェーハはこれらのモジュールを何度も巡ります。成膜、リソグラフィ、エッチングまたはイオン注入、洗浄、計測を経て、次の層へ進みます。モジュールの分担を紹介したあと、この本ではループの中心であるリソグラフィから説明を始めます。

|---|---|
| [第 4 章　ファブの 7 つのモジュール](04-fab-modules/README.md) | PH、DF、TF、ET、IMP、CMP、WET がそれぞれ何をするか、ルートがその間をどう行き来するか |
| [第 5 章　リソグラフィ](05-lithography/README.md) | マスク、レジスト、露光装置で回路をウェーハに「印刷」する |

| [第 8 章　イオン注入と熱処理](08-ion-implantation/README.md) | ドーズ、エネルギー、アニール、熱履歴 |
| [第 9 章　CMP](09-cmp/README.md) | ウェーハを平らに磨く：スラリー、ディッシング、エロージョン、ダミーパターン |
