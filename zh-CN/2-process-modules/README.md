# 第 2 部　工艺模块

晶圆厂里的步骤多达数百到上千个，但大部分都是由几种基本的「工艺模块」反复组合而成。这一部逐一介绍每个模块：它在做什么、用什么设备、要看哪些指标、常出什么问题。

实际生产时，晶圆会在这些模块之间反复循环：铺上薄膜、光刻、刻蚀或注入、清洗、测量，然后再往上做下一层。本书从光刻开始介绍，因为它是整个循环的核心。

| 章节 | 你会读到 |
|---|---|
| [第 4 章　光刻](04-lithography/README.md) | 掩模版、光刻胶与曝光机，把电路图「印」到晶圆上 |
| [第 5 章　薄膜](05-thin-films/README.md) | 热氧化、CVD、PVD、ALD 与外延 |
| [第 6 章　刻蚀](06-etching/README.md) | 干法刻蚀与湿法刻蚀、等离子体、选择比与终点检测 |
| [第 7 章　离子注入与热处理](07-ion-implantation/README.md) | 剂量、能量、退火与热预算 |
| [第 8 章　CMP](08-cmp/README.md) | 把晶圆磨平：抛光液、碟形凹陷、侵蚀与填充图形 |
| [第 9 章　清洗与污染控制](09-cleaning/README.md) | RCA 清洗、Q-Time 与交叉污染 |
| [第 10 章　金属化](10-metallization/README.md) | 接触孔、铜的大马士革工艺与低介电常数材料 |
