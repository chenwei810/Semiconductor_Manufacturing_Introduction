# 第 2 部　工艺模块

晶圆厂里的步骤多达数百到上千个，但大部分都是由几种基本的「工艺模块」反复组合而成。这一部先用一章介绍工厂里负责各段工艺的七个 Module，再逐一介绍每个模块：它在做什么、用什么设备、要看哪些指标、常出什么问题。

实际生产时，晶圆会在这些模块之间反复循环：铺上薄膜、光刻、刻蚀或注入、清洗、测量，然后再往上做下一层。介绍完 Module 的分工之后，本书从光刻开始，因为它是整个循环的核心。

| [第 5 章　光刻](05-lithography/README.md) | 掩模版、光刻胶与曝光机，把电路图「印」到晶圆上 |
