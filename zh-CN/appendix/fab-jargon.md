# 附录 B　现场行话

晶圆厂的日常沟通，常常是中文夹杂英文术语，例如「这批 Q-Time 快到了，先跑它」。刚入行的人第一次听到，常常一头雾水。

本附录收录晶圆厂里常听到的说法，并附上例句。各公司的习惯用语不完全相同，本附录保留原作的现场行话；不同地区与工厂可能使用不同称呼，不能据此认为所有说法在中国大陆通用。正式的术语定义请见[附录 A 术语总表](glossary.md)。

## 晶圆与批次

| 行话 | 意思 | 例句 |
|---|---|---|
| Lot | 一批晶圆，最多 25 片 | 「这个 Lot 今天要出货。」 |
| 投片（Wafer Start） | 把空白晶圆投入生产 | 「这个月的投片量增加了。」 |
| Fab Out | 晶圆完成前段工艺，离开晶圆厂 | 「这批预计下周 Fab Out。」 |
| Hot Lot | 优先生产的急件 | 「这批是 Hot Lot，到站先跑。」 |
| Split | 把一批晶圆分成几组，做不同条件 | 「这批要 Split 成三组条件。」 |
| Merge | 把分开的晶圆合回同一批 | 「实验做完就 Merge 回去。」 |
| Bank | 让晶圆暂停在某个步骤等待 | 「这批先 Bank 在金属层前面。」 |
| WIP | 还在生产线上的晶圆 | 「黄光前面的 WIP 堆太多了。」 |
| Move | 一段时间内晶圆完成的步骤数，用来衡量产出 | 「今天全厂的 Move 有达标吗？」 |
| 控片 | 用来检查设备状态的测试晶圆（Monitor Wafer） | 「先跑一片控片确认膜厚。」 |
| 挡片 | 用来填补空位或调整设备的晶圆（Dummy Wafer） | 「炉管空位记得补挡片。」 |
| 破片 | 晶圆破裂 | 「机械臂取片时破片了。」 |

## 设备

| 行话 | 意思 | 例句 |
|---|---|---|
| Recipe | 设备执行工艺用的参数组合 | 「这道的 Recipe 换新版本了。」 |
| PM | 定期保养 | 「这台今天下午排 PM。」 |
| Down（Down 机） | 设备故障或停用 | 「刻蚀机 Down 了，已经通知 EE。」 |
| 复机 | 设备修好、恢复生产 | 「这台预计晚上复机。」 |
| Qual | 确认设备状态合格的验证 | 「PM 完要先 Qual 过才能跑货。」 |
| Seasoning | 保养后先跑挡片，让腔体稳定 | 「先 Season 二十片挡片。」 |
| Chamber | 设备中实际做工艺的腔体 | 「这片是在 B 腔做的。」 |
| Idle | 设备闲置、没有晶圆可跑 | 「这台 Idle 很久了。」 |
| 绑机（Dedication） | 指定晶圆只能在特定设备上做 | 「这层要绑同一台曝光机。」 |
| Load Port | 设备前方放晶圆盒的平台 | 「Load Port 读不到 FOUP 的编号。」 |

## 系统与流程

| 行话 | 意思 | 例句 |
|---|---|---|
| 进站（Track-in） | 在系统上登记开始加工 | 「货放上去记得先进站。」 |
| 出站（Track-out） | 在系统上登记完成加工 | 「设备跑完了，记得出站。」 |
| Hold | 暂停晶圆或设备的生产 | 「这批被 Hold 了，原因是 Q-Time 超过。」 |
| Release | 解除 Hold，放行继续生产 | 「工程师确认没问题，可以 Release。」 |
| Q-Time | 两站之间允许等待的时间 | 「这批 Q-Time 快到了，先跑它。」 |
| 派工 | 决定设备下一批要跑哪一批晶圆 | 「派工系统把这批排在最前面。」 |
| 跑货 | 让产品晶圆在设备上生产 | 「这台现在可以跑货了吗？」 |
| 账实不符 | 系统记录和实际状况不一致 | 「系统显示已出站，晶圆却还在设备里，账实不符。」 |

## 质量与异常

| 行话 | 意思 | 例句 |
|---|---|---|
| OOC | 数据超出控制限 | 「这点 OOC 了，照 OCAP 处理。」 |
| OOS | 数据超出规格 | 「膜厚 OOS，要开 MRB。」 |
| Rework | 重新制作，主要用在光刻 | 「ADI 没过，要 Rework。」 |
| Scrap | 报废 | 「这片破片了，只能 Scrap。」 |
| Excursion | 突发的质量异常事件 | 「昨天那次缺陷的 Excursion 影响了三批。」 |
| MRB | 跨部门判定不合格品处置的会议 | 「这批要开 MRB 决定。」 |
| Map | 晶圆图 | 「看一下这片的 Map 有没有刮痕。」 |
| Particle | 微粒 | 「这片的 Particle 数超标。」 |

## 区域与人

| 行话 | 意思 | 例句 |
|---|---|---|
| 黄光 | 光刻区，因照明是黄色而得名 | 「这批卡在黄光。」 |
| 炉管 | 氧化、退火等批式高温设备的区域 | 「炉管今天组批比较慢。」 |
| Wet | 湿法清洗与湿法刻蚀区 | 「这道要先到 Wet 洗一下。」 |
| PE、EE、PIE、YE | 工艺、设备、工艺集成、良率工程师 | 「这个问题要找 PIE 判断。」 |
| 交接 | 换班时说明设备与晶圆的状况 | 「交接时要讲清楚这台还在观察。」 |
